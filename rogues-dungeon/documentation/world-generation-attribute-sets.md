# World-generation attribute sets

Each set has ten player-facing attributes where a higher value is always better. Use a 0-5 range for each attribute and give the player 30 points to distribute.

## Adventurer's contract

| Attribute | Higher value means |
| --- | --- |
| Peace | Fewer enemies and less aggressive patrols |
| Mercy | Weaker enemies and fewer elite enemies |
| Safety | Fewer traps and dangerous terrain features |
| Guidance | Exit stairs are closer and easier to reach |
| Clarity | Simpler layouts with fewer dead ends |
| Fortune | More gold and stronger equipment |
| Plenty | More ore and crafting materials |
| Comfort | More healing items, campfires, and safe rest points |
| Discovery | More secret rooms, alternate routes, and rare events |
| Fellowship | More friendly NPCs, quests, and useful encounters |

## Blessed realm

| Attribute | Higher value means |
| --- | --- |
| Tranquility | Fewer hostile creatures and conflicts |
| Protection | Safer terrain and fewer harmful curses |
| Prosperity | More treasure, merchants, and valuable drops |
| Abundance | More food, potions, ore, and useful supplies |
| Hospitality | More settlements, friendly NPCs, and helpful factions |
| Harmony | Fewer faction disputes and hostile territory |
| Illumination | Better visibility and fewer dark or corrupted areas |
| Guidance | Clearer routes and more reachable objectives |
| Heritage | More ruins, relics, lore, and meaningful landmarks |
| Wonder | More shrines, magical discoveries, artifacts, and special events |

## Dungeon comfort

| Attribute | Higher value means |
| --- | --- |
| Compactness | Smaller floors and shorter routes to the exit |
| Simplicity | Fewer branches, loops, and confusing dead ends |
| Openness | More open routes and fewer locked doors |
| Safe footing | Fewer traps, pits, and environmental threats |
| Easy victories | Weaker enemies and fewer elites |
| Rich rewards | More gold, equipment, and treasure rooms |
| Crafting supply | More ore and upgrade materials |
| Recovery | More healing, potions, and campfires |
| Hidden bounty | More secret rooms and optional rewards |
| Quest support | More clear quest markers, helpful NPCs, and relevant encounters |
